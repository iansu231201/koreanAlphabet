# koreanAlphabet 韓文字母發音表

給中文使用者的韓文（한글）發音學習網站，每個字都能點擊聽發音，並附羅馬拼音與注音近似音。

👉 **https://iansu231201.github.io/koreanAlphabet/**

## 功能

### 發音
依類別分頁，點卡片即播放發音。
- **子音（19）**：基本子音與雙子音，附子音名稱（기역、니은…）、平音／激音／緊音分類
- **母音（21）**：基本母音與複合母音
- **尾音（27）**：依 7 種代表音 [k] [n] [t] [l] [m] [p] [ng] 分組，標示實際讀法（例：앍 讀 [악]）
- **子音＋母音（399）**：19 個子音 × 21 個母音的組合表，可逐列查看或顯示全表

### 組合
選擇「子音＋母音＋尾音」即時組出字並播放，涵蓋全部 11,172 個韓文音節，並顯示組成、羅馬拼音、注音近似音與實際發音。

### 練習
字卡亂序出題，看到字先自己唸，再顯示答案聽正確發音；選「再練」的題目會在幾題後再出現。
- **單字練習**：一次一個字，範圍可選「無尾音（399）」、「常用字（2,350，KS X 1001）」或「全部（11,172）」
- **詞語練習**：122 個常用詞語與短句（問候、數字、人物、食物、地點、日常），附中文意思與音變後的讀法（例：한국어 讀作 [한구거]）

## 發音說明

- 語音為微軟 Edge 神經網路語音 `ko-KR-SunHiNeural`（女聲），事先產生成 mp3 放在網站中，**瀏覽時不需呼叫任何外部服務**。
- 單獨一個字時，尾音只有 7 種代表音（닭→[닥]、값→[갑]），所以複合尾音的字播放其代表音字的錄音，以符合韓語標準發音。
- 羅馬拼音採用韓國文化觀光部的「國語羅馬字表記法」。
- 注音僅為近似音，韓語的平音、激音、緊音在注音上無法區分，請以實際聲音為準。
- 已知限制：語音引擎將 쇼/쑈、셀/쎌、뮌/뮨 讀成相同的聲音。

## 開發

使用 Nix flake 建立開發環境，網站為純靜態 HTML／CSS／JavaScript，不需建置。

```bash
nix develop                        # 進入開發環境（python + edge-tts、ffmpeg、gh）
python scripts/gen_audio.py        # 產生缺少的語音檔（已存在的會跳過）
python scripts/check_audio.py      # 檢查語音檔是否齊全、長度正常
python -m http.server -d site 8000 # 本機預覽 http://localhost:8000
```

- 新增練習詞語：編輯 `site/words.json` 後執行 `gen_audio.py`
- 部署：push 到 `main` 後，GitHub Actions 會自動將 `site/` 發佈到 GitHub Pages
